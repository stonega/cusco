# Linear icon source

`linear.svg` uses the official `logo-light.svg` logomark from Linear Brand
Assets v3, downloaded from the
[Linear brand guidelines](https://linear.app/brand) on 2026-08-29. It is placed
on Linear's brand-color tile with padding so the mark stays crisp at GNOME
avatar sizes without relying on SVG blend-mode filters.

Use of the asset is subject to Linear's brand guidelines.
