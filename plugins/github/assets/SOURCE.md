# GitHub icon source

The Invertocat geometry in `github-small.svg` comes from the official
`GitHub_Invertocat_White_Clearspace.svg` included in
[GitHub's logo download](https://brand.github.com/GitHub_Logos.zip), retrieved
on 2026-08-30. The official white mark is shown on a flat `#24292F` tile so it
keeps maximum contrast when Cusco loads it as a standalone texture in either
GNOME theme. The logo geometry is unchanged.

Use of the mark is subject to GitHub's
[brand and logo guidelines](https://brand.github.com/foundations/logo).
